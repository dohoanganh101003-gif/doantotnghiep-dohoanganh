

# 🧠 1. TƯ DUY ĐÚNG VỀ KIẾN TRÚC

Bạn đang có 2 thành phần:

## 🗄️ PostgreSQL + PostGIS (DB)

→ Lưu dữ liệu thật (CRUD)

## 🌍 GeoServer

→ KHÔNG lưu dữ liệu
→ CHỈ đọc dữ liệu từ DB để hiển thị (WMS/WFS)

👉 Kết luận quan trọng:

> ❗ Khi bạn thêm/sửa/xóa → CHỈ ghi vào DB
> ❗ GeoServer tự đọc lại → KHÔNG cần lưu riêng

---

# 🔁 2. LUỒNG HOẠT ĐỘNG CHUẨN (END-TO-END)

## 🟢 BƯỚC 1: Người dùng vào trang chủ

* URL: `/`
* Hệ thống:

  * Load Leaflet
  * Load WMS từ GeoServer

👉 Hiển thị bản đồ + nhà máy

---

## 🔐 BƯỚC 2: Đăng nhập

* `/dangnhap`
* Server:

  * Check user DB
  * Lưu `session`

👉 Phân quyền:

* user → chỉ xem
* admin → CRUD

---

## ➕ BƯỚC 3: Thêm nhà máy

### Người dùng:

* Bấm: “Thêm nhà máy”
* → `/themnhamay`

### Nhập:

* tên
* công suất
* trạng thái
* lat/lng

### Khi submit:

```plaintext
Frontend → POST /api/solar
        ↓
Controller
        ↓
Model
        ↓
PostgreSQL (INSERT)
```

👉 Dữ liệu đã nằm trong DB

---

## 🔥 QUAN TRỌNG NHẤT

### Sau khi thêm:

```js
wmsLayer.setParams({ time: new Date().getTime() });
```

👉 GeoServer sẽ:

```plaintext
GeoServer → đọc lại DB → render lại WMS
```

✅ Nhà máy mới xuất hiện trên bản đồ

---

## ✏️ BƯỚC 4: Sửa nhà máy

### Người dùng:

* vào `/danhsach`
* bấm “Sửa”

### Luồng:

```plaintext
PUT /api/solar/:id
      ↓
DB UPDATE
      ↓
Reload WMS
```

👉 GeoServer hiển thị dữ liệu mới

---

## ❌ BƯỚC 5: Xóa nhà máy

```plaintext
DELETE /api/solar/:id
        ↓
DB DELETE
        ↓
Reload WMS
```

👉 GeoServer tự mất điểm đó

---

# 🧩 3. SƠ ĐỒ LUỒNG TỔNG QUÁT

```plaintext
[User]
   ↓
[Frontend - EJS + JS]
   ↓
[Node.js API]
   ↓
[PostgreSQL + PostGIS]  ← (CRUD xảy ra ở đây)
   ↑
[GeoServer]
   ↓
[Leaflet Map (WMS)]
```

---

# ❗ 4. TRẢ LỜI CÂU HỎI CỦA BẠN (RẤT QUAN TRỌNG)

## ❓ “Thêm nhà máy có lưu vào GeoServer không?”

👉 ❌ KHÔNG

## ✔ Thực tế là:

| Thành phần | Vai trò           |
| ---------- | ----------------- |
| Node.js    | xử lý logic       |
| PostgreSQL | lưu dữ liệu       |
| GeoServer  | đọc & hiển thị    |
| Leaflet    | hiển thị frontend |
